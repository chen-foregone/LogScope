## 验收标准
- [ ] 证据详情持久显示来源、日志发生时间、查询条件、脱敏片段或稳定定位及脱敏说明；缺最低追溯字段不得作为充分确认依据。
- [ ] 密码、令牌、密钥及会话凭据直接屏蔽，姓名、电话、邮箱、证件替换一致代号；敏感关联标识也处理。
- [ ] 同调查同身份跨日志代号一致，不同调查独立，算法不依赖额外保存原敏感值；尽量保留错误码、时间及安全关联线索。
- [ ] 无法可靠脱敏的内容不保存为可分析证据、不交 Agent，UI 提示不可用且提示本身不泄漏原值。
- [ ] 持久产物、API响应、UI、错误与诊断输出都无测试注入的原敏感值，异常路径没有脱敏旁路。
- [ ] 只有有效调查、目标运行轮和执行身份可提交；普通用户不能绕过身份自由写证据，跨调查错误归属被拒绝。
- [ ] 成功新增证据更新最后更新时间，读取不更新；刷新重启后脱敏核验材料可读，旧轮不被覆盖。

## 测试与完成证据
以 HTTP API + 真实 PostgreSQL 注入含敏感字段的受控外部材料，检查实际存储、响应、UI及错误输出，提供脱敏断言与拒绝证据；增量 UI E2E 查看核验字段。代号跨轮由12验收，真实脱敏入口由18、19补。替身不证明真实日志协议或 Agent 集成，完成须贯通 schema/API/UI。
