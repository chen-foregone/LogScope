## 验收标准
- [x] 历史证据默认不继承，显式纳入前检查本轮服务、固定日志范围与仍可核验性；不符合条件拒绝并显示原因。
- [x] 纳入后显示来源轮次和核验材料，原轮归属、证据与历史计数不变，引用不表示本轮覆盖完整。
- [x] 同一证据在本轮重复或并发引用只计一次，新获取与历史引用可靠判同后不双计；仅历史独存不计本轮。
- [x] 调整服务或范围后的新轮不得把上一轮覆盖自动当作新范围覆盖，不借引用绕过服务/时间检查。
- [x] 同调查跨日志跨轮同身份代号一致，不同调查独立；凭据直接屏蔽、敏感关联标识处理，数据库及错误输出无原值。
- [x] 引用绑定调查、目标轮和有效写入阶段，已结束或隔离的执行不能迟到纳入；不通过引用覆盖历史。
- [x] UI/API显示本轮真实条数与来源轮，实际新增纳入更新最后更新时间，重复无变化或读取不更新，刷新后关系与代号不变。
