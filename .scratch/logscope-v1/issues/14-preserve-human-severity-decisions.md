## 验收标准
- [ ] 高为核心业务不可用或大范围用户无法完成关键操作；中为部分受损或明显变慢但有替代路径；低为局部轻微且不妨碍关键业务；信息不足为未评估。
- [ ] 原因不明不降级，未评估不等于低风险；依据尽量说明业务、用户范围、持续情况与替代路径，不用根因可信度或优先级代替业务影响。
- [ ] Agent评估与人工调整每次记录来源、依据、评估时间及追加历史，缺依据拒绝，不覆盖过去版本。
- [ ] 人工调整后Agent只能提交新建议及依据，不能直接覆盖；用户明确确认才应用，UI区分当前人工等级与待确认建议。
- [ ] 过时或并发确认不能覆盖较新人工决定，请求重放不重复应用同一建议；旧执行等级产物仍受身份隔离。
- [ ] 新轮保留人工等级、评估时间和历史影响提示，明确保留不等于已验证当前影响，不能自动清空或静默更新评估时间。
- [ ] 实际等级变化更新最后更新时间，读取不更新；刷新重启后当前等级、建议及完整变更历史一致，UI显示四种取值。

## 测试与完成证据
HTTP API + 真实 PostgreSQL 验证四等级定性案例、依据缺失、人工后建议、确认重放和过时并发、跨轮保留及旧执行拒绝；提供真实API UI确认和历史证据。可控Agent只验适配行为，19必须用真实Agent验证人工边界。完成包含 schema/API/UI 与版本竞争测试。
