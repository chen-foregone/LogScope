# 17: 预览并确认清理到期调查产物
Status: ready-for-agent
Type: task
Blocked by: 12, 16

## What to build
纵向交付清理范围/确认身份 schema、预览与确认API、到期待确认和不可恢复提示UI；只清指定调查产物，不触及源日志或其他调查材料。

## Blocked by
- 12 引用历史证据并保持跨轮一致性
- 16 显示保留期限并支持到期提示与延期

## Spec
[首版实施规格](../spec.md)：D4、D7、D8。
用户故事主要交付：US-45、US-46；US-47 清理竞争部分。
验收组主要交付：A31；A35 清理范围提示与确认部分。

## 开工门槛
无额外未知输入，遵守12、16依赖及选定延期契约。预览版本/确认身份、引用保护与事务重核是授权内设计，不另添自动清理规则；不把本地文档工单创建误认为已授权执行真实删除。

## 验收标准
- [ ] 到期仅进入待用户确认清理，后台到期处理不静默永久删除，未到期或运行中不能直接清理。
- [ ] 预览明确指定调查的记录、逐轮尝试、脱敏证据、引用、结论及变更历史的实际清理范围，说明不可恢复性。
- [ ] 用户显式确认绑定本次预览范围与版本或等价身份，确认前不永久删除，确认后返回真实结果。
- [ ] 确认与新轮启动、延期竞争时事务重核当前期限、运行状态和预览范围，过时确认拒绝或要求重新预览，不清理运行调查。
- [ ] 保护共享材料及引用：只处理指定调查范围，不使其他调查仍需证据静默失效；不删除被调查环境的原始日志。
- [ ] 重试/重复确认结果一致可理解，不重复扩大范围，不误删其他调查；失败不留下误导成功的半套清理结果。
- [ ] UI E2E显示到期待确认、真实范围、不可恢复提示及确认结果，API和持久化事实一致，不用样例成功提示。

## 测试与完成证据
HTTP API + 真实 PostgreSQL，配可控时间经业务流程形成到期与共享引用材料，验证确认前保留、确认后范围、重放、启动/延期竞争及源日志未写。提供清理前后范围对照与真实API UI E2E。仅受控验收环境执行破坏性测试；完成包含 schema/API/UI、引用安全与竞争证据。
