## What to build

用户手动启动后，本机受控 worker 获取模拟日志的脱敏证据，通过 LangChain 与 LangGraph 调用百炼 qwen-plus，保存首轮假设和运行摘要，并可在详情页查看。此切片即包含安全、预算与停止底线，不能等待后续工单才补齐。

## Acceptance criteria

- [ ] 配置缺失默认不调用；端点与地域匹配，密钥仅服务端注入，错误和产物不含秘密原值。
- [ ] 接纳、事务提交、唯一执行领取衔接可靠；模型调用不占数据库长事务。
- [ ] 固化范围内获取模拟来源证据，先脱敏再交模型；页面明确标记模拟来源与实际模型。
- [ ] 版本化保存首轮待验证假设、证据引用与运行状态，刷新后可读取，旧协议兼容。
- [ ] 首次真实调用前已具备累计 10 元预算预留、有限输入输出和调用上限；无法可靠估价时不调用。
- [ ] 取消、超时或身份失效后不安排新动作，迟到产物被拒绝；未安全确认退出不得释放名额。
- [ ] HTTP API、真实 PostgreSQL、浏览器 UI 和可控模型替身验证主路径与失败路径。真实调用前核实访问条件，不伪造验收。
