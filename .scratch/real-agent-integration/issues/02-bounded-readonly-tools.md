## What to build

模型根据缺失证据请求白名单工具，受控补查模拟日志并继续分析。用户能看到查询覆盖、来源错误及循环结束原因，而不是无限运行的黑盒。

## Acceptance criteria

- [x] 模型只能请求允许的查询和本轮证据读取；身份由后端绑定，无法扩大服务、来源及时间范围。
- [x] 每次工具和模型调用前重新校验身份、停止状态、截止时间和剩余预算。
- [x] 复用查询重试、覆盖、脱敏和去重规则；工具参数非法、未知工具及恶意日志不能触发自由执行。
- [x] 循环次数、工具次数、材料大小和输出有界；达到限制时保留已有材料并展示真实原因。
- [x] 无证据、部分来源不可用、超时及工具失败不被解释为没有故障。
- [x] API 与 UI 测试覆盖多轮成功、越界、重复查询、提示注入、工具预算及取消期间拒绝新动作。
