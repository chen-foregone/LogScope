[19](../../logscope-v1/issues/19-connect-real-agent-and-analysis-loop.md)；[规格](../spec.md)。

## What to build

用户查看依赖、资源、配置、权限、应用错误和未知类型的分析依据、机制、矛盾、替代解释及建议，并能定位证据；证据失效后可手动新轮核验，保留历史。

## Acceptance criteria

- [ ] 新协议保存有界、脱敏的现象、解释、证据引用、矛盾、替代解释、缺口及只读建议；兼容历史协议和展示。
- [ ] 模型声称 confirmed 不直接确认。没有充分可核验支撑的新类型保存为待验证假设，不能以数量或时间相关确认。
- [ ] 引用必须来自本轮已纳入证据；拒绝编造、重复、不合范围及不满足有效性规则的引用。
- [ ] 证据不足可正常已完成／未确定根因，技术失败独立表达。
- [ ] 关键证据失效呈现待重新核验；只能手动新轮获得充分支撑后恢复，不能自动续跑或覆盖历史。
- [ ] 页面显示分析边界和模拟来源，可跳转证据；建议不产生环境写操作。
- [ ] API、数据库及 UI 测试覆盖新旧产物、多个类别、非法产物、证据失效与手动核验；另留语义评审案例。
