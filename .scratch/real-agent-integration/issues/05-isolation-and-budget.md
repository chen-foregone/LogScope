## Acceptance criteria

- [ ] 最多三调查、不排队；并发费用预留不能重复消费累计 10 元余额，金额固定精度且可审计。
- [ ] 超时和响应丢失保留不明费用预留；无隐式重试，价格或用量无法安全核算时拒绝新增真实调用。
- [ ] 取消、超时、失联停止安排动作；本机执行和工具未安全确认前不释放名额。
- [ ] 旧执行迟到的证据、结论及严重程度均被拒绝；已保存历史仍可追溯。
- [ ] checkpoint 仅保存脱敏状态；不含密钥、原始敏感材料或完整思维链；重启不会自动续跑旧图。
- [ ] UI 显示正在停止、正在确认执行状态、预算不足及估算费用，不把连接断开当成安全终止。
- [ ] 真实 PostgreSQL 并发测试、本机进程故障测试及 UI 回归覆盖上述行为，标明替身范围与剩余风险。
