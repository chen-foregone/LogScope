# 02: 评估模型如何保留矛盾、多个方向及因果不确定性
Status: needs-triage
Type: task

## 问题与证据

四类案例已揭示原始模型语义失败，见[逐例评审](../validation.md)。本项记录后续改进，不把新增案例测试通过当作原始推理修复。

- 不同请求代号不足以证明原因相互独立，共同代号与时间也不足以证明因果。
- 权限拒绝和连接池占用应作为不同观测保留；没有传播证据不能解释彼此。
- 明确unresolved的轨迹不能被描述为没有矛盾；匿名依赖不能绑定Redis。
- 根因、影响人数和持续时间没有观测时必须保留不确定性；不得自报已确认根因。

## 后续范围
