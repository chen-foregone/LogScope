# 01：接通可控模拟只读日志来源
Status: wontfix
Type: task

## What to build

交付独立本地只读HTTP模拟日志服务、后端受控协议适配及结果纳入链路、明确标识模拟来源的证据UI。使用合成数据验证固定调查范围、执行身份、脱敏、可靠判同、有限重试、来源闸门和停止确认，不冒充真实来源验收。

## Spec

[可控模拟只读日志来源规格](../spec.md)。本工单覆盖该规格全部范围，实施前先按阶段约定提交方案和变更清单，等待方案确认；ready-for-agent 表示规格可用于规划，不替代实施授权。

## Dependencies

复用原计划工单04、06的已交付能力。真实来源工单18不是本工单的前置阻塞，本工单也不解除18的 needs-info 状态。

## Acceptance Criteria

- [ ] 显式启用开发配置后可独立启动本地只读HTTP模拟来源，默认不启用；提供可重复合成数据及运行说明。
- [ ] 经业务HTTP API和真实PostgreSQL完成查询到脱敏证据入库的完整链路，不通过测试直接写库替代业务行为。
- [ ] 浏览器不可指定任意端点、凭据或范围；材料写入重新验证有效执行身份、固定范围及截止时间。
- [ ] 来源返回及错误先经过严格契约处理；自由文本、不支持字段及不可靠脱敏材料拒绝，敏感原值不进入持久材料、UI或诊断。
- [ ] 复用现有证据写入规则；可靠身份重复只计一次，不同ID同文本不合并，同身份内容变化拒绝，无身份逐条保留并提示可能重复。
- [ ] 模拟协议覆盖超时、临时故障、权限/凭据/参数错误、限流和部分来源缺失；沿用30秒单次、10分钟总预算、额外两次及2秒/5秒规则。
- [ ] 验证跨调查闸门及取消/超时后的写隔离、HTTP实际退出与连接清理；不得持数据库业务锁跨来源网络等待。
- [ ] 明确证据逐条提交边界；后续失败不撤销此前已提交材料，未提交写入回滚，重试不虚构可靠去重。
- [ ] UI明确显示模拟来源、来源状态及缺失提示；API/UI证据条数一致，刷新和重启可读，不暗示真实来源或根因已验收。
- [ ] 提供类型检查、专项和完整测试记录，分别标记实际HTTP、受控时钟及故障注入证据；不复用历史成绩冒充本工单成绩。
- [ ] 最终交付模块学习总结及6至8道不附答案的问题，满足规格中的教学要求，不等待答题才完成实现。
- [ ] 原工单18保持真实接入未完成，其只读账号、真实协议与A33仍待后续补验。
